Companies with a known job-board platform (Workday, Greenhouse, Lever, SmartRecruiters) or a built-in integration already get a real search automatically — this is for everyone else. When set, pinned Role Titles are substituted into {q} (and {location}/{q-slug}/{location-slug} where supported) and sent as an actual query to the site's own search, instead of just scanning whatever the plain Career Site link happens to show.
Add Source
Use {q} (and {location} if the site supports it) where your search terms should go — Open/Search will substitute them in. No placeholder means a generic ?q= gets appended instead, which only works on some sites.
